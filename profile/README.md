# Syanic Launcher

An upcoming free and open-source Minecraft launcher focused on simplicity, performance, and a clean user experience.

The project is currently under active development and repositories are not yet public.

## Community

* Discord: https://dsc.gg/syaniclauncher
* YouTube: [@SyanicXD](https://youtube.com/@SyanicXD)
* GitHub: [@xsyanic](https://github.com/xsyanic)

## Status

Syanic Launcher is not ready for public use. Development progress, announcements, and early previews will be shared through the community channels above.
